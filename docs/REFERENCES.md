# References and provenance

The RandCeph training and analysis files were collected from the experiment project's code directory. Release preparation changed machine-specific paths to repository-relative defaults or environment variables and updated method display labels to RandCeph. Model architecture, affine transforms, augmentation distributions, loss, and metric definitions were retained.

## Published comparison benchmark

Özcan and Allaf. *Cross-Domain Generalization of Deep Learning Architectures for Cephalometric Landmark Detection: A Dual-Dataset and Multi-Device Benchmark*. Diagnostics 2026, 16(17), 2726. [DOI: 10.3390/diagnostics16172726](https://doi.org/10.3390/diagnostics16172726).

The constants named PUBLISHED, PUBLISHED_GD, PUBLISHED_JOINT, PUBLISHED_LODO, PUBLISHED_LM, and PUBLISHED_SDR2 in common.py come from that paper's tables, caption, or supplement. They are literature summaries, not measurements generated by RandCeph. The cross-domain SDR range is pooled and does not assign a value to an individual method.

The optional adapters `code/pilot_repro.py` and `code/repro_cached.py` read the original supplementary `m8_multiseed.py`. Download the original supplement from the benchmark paper and place it at:

```text
supp/diagnostics-16-02726-s001/code/m8_multiseed.py
```

The supplement itself is not redistributed. Its dependencies, including timm, must be installed separately. These adapters perform exact text substitutions and are specific to the supplement version used in the experiment.

```bash
python code/repro_cached.py HRNet 0,1,2
```

The internal suffix [P] denotes published values where used in figures. Optional baseline reruns and their source annotations are retained as separate experimental evidence.
